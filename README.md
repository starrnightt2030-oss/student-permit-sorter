# فرز تصاريح الطلاب — Student Permit Sorter

PWA عربي Mobile-First لفرز تصاريح الطلاب باستخدام البحث الصوتي أو النصي.

## الملفات
- index.html — الواجهة
- style.css — التصميم
- app.js — منطق التطبيق وExcel وIndexedDB والبحث الصوتي
- manifest.json — إعدادات PWA
- sw.js — Offline Service Worker
- icon.svg — أيقونة التطبيق

## الاستخدام
1. افتح التطبيق عبر GitHub Pages أو أي Static Hosting.
2. اختر «بيانات تجريبية» للتجربة أو «استيراد Excel» لملف الطلاب.
3. اضغط «تحدث» وانطق اسم الطالب.
4. راجع التخصص واضغط «تم فرز التصريح».

أعمدة Excel المدعومة: رقم الطالب، اسم الطالب، التخصص.

> ملاحظة: البحث الصوتي يعتمد على Speech Recognition المتاح في المتصفح. بعد تثبيت التطبيق وحفظ البيانات محليًا، يعمل البحث والبيانات دون اتصال؛ أما تحويل الكلام إلى نص فقد يعتمد على دعم المتصفح/النظام.
